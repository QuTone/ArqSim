# Bundled benchmark catalog

This directory is a convenience workload catalog for the ArqSim HTTP
adapter. It is not a single-source benchmark suite and is not evaluation-result
evidence.

For each family:

- `original-circuit/` holds the source-layer input used by this catalog;
- `clifford+T/` and `pbc/` hold local normalized derivatives when available;
- the derivative files inherit the origin and license of their source-layer
  input; and
- `arqsim_timeline_demo` is owned by ArqSim and covered by the repository's
  Apache-2.0 license.

The exact historical command line that produced every retained derivative was
not frozen. Treat these files as catalog inputs, not as a byte-reproducible
transformation oracle. A future regeneration must record the tool version,
parameters, source hash, and output hash together.
